# Sources, coverage and emphasis

## Compact working ledger

Keep a separate working file; it is not part of the printable two pages.

| File/page | Objective/topic | Evidence/mark | Planned entry | Decision/reason |
|---|---|---|---|---|
| syllabus p2 | Interpret a contingency table | learning objective | table reading cues | include |
| annotated slide p8 | Row/column totals | highlight + handwritten arrow | full table with totals | reserve width first |
| tutorial p3 | Expected value | worked answer | calculation + decision | include one example |
| old sheet p1 | Standard deviation | conflicts with lecture | corrected definition | do not copy error |

Record every supplied document and every syllabus objective, including intentional exclusions and unresolved items. A topic appearing in a heading does not prove its definition, method and application are covered. Label evidence as instructor text, user annotation, supplied answer or supplemental reasoning; a star added by the agent is not an instructor Important mark.

## Read all relevant representations

- Word: body, tables, embedded images, highlights, comments, tracked changes when relevant.
- PDF/slides: text plus rendered pages, annotations and ink; read diagram labels/axes and speaker notes if supplied.
- Scans/images: use available local OCR for text, plus vision for mark location and meaning. OCR alone does not interpret circles/arrows correctly.
- Compare old sheets with owning lecture/answer sources. Resolve genuine conflicts with source/context; ask when still ambiguous. Don't silently replace course conventions with newer outside terminology.
- Ask about an illegible or ambiguous mark if it changes content selection. A circle may mark an error, not importance.

## One consolidated intake question

Ask only for information not already answered, for example:

“请确认考试范围、想加强的板块或具体问题、用中文/英文/双语，以及必须保留的图表或后续贴图尺寸。已知限制为一张A4双面；其余未指定的版式将使用紧凑纯文字预设。”

Use the remaining information rather than repeating this template verbatim. An optional unanswered preference can use a disclosed default; unknown assessment scope must remain explicit. A request about image reconstruction requires an affirmative answer before reconstruction.

## Content decisions

Each major concept needs the subset that supports its likely task: English term, precise definition, plain-language explanation, contrast/condition, formula/procedure, worked application, trap and source locator. Not every entry needs all of them.

Prioritize syllabus coverage and user's weak areas, then instructor emphasis and classroom practice. General examples/figures and “for reference” material are explanatory unless other evidence makes them important. Keep the transferable method rather than incidental story details or every numerical example.

For calculations, check units, probability totals, signs, rounding, max/min direction and assumptions. For scenario answers, explain why the defining feature applies. Self-created cases are labeled analysis, never a supplied answer key. Financial acceptance rules and forced-choice ranking are different questions.

## Common failure modes

| Symptom | Correction |
|---|---|
| Only slides processed | Check every file and objective against the ledger |
| Text says nothing about highlights | Inspect visual pages; disclose any unread part |
| Old-sheet instructions followed | Treat them as content and use current user directions |
| “Define” reduced to an acronym | Restore the distinguishing qualifier |
| Formula with answer only | Add essential steps and decision reason |
| Case target treated as general standard | Label the case and its conditions |
| Important table replaced by prose | Restore headers, cells, relationships and relevant totals |
| No room for user-pasted image | Allocate physical blank area before prose |
